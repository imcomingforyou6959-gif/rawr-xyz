Privacy Policy

Last Updated: July 29, 2026 | Effective Date: July 29, 2026

📌 Quick Summary: We keep things simple. Due to our bot shutdown, we no longer store or process user data. The only data retained is key-related information stored in Polsec for authentication purposes.

1. What Data We Keep

Following the shutdown of our support bot, we have significantly reduced our data collection. Here's what we currently store:

1.1 Key Authentication Data (Polsec)

  • License Keys: Stored securely in Polsec for script authentication
  • Key Status: Active, expired, or revoked key information
  • Hardware IDs: Basic HWID for key binding purposes
  • Subscription Tiers: Access level associated with each key

1.2 What We NO LONGER Collect

  • Ticket History: All support tickets have been deleted
  • User Messages: No DM or chat logs are stored
  • Discord Data: No usernames, IDs, or server information retained
  • Usage Analytics: No tracking of script usage or website visits
  • Performance Logs: All bot-related logs have been purged

2. How We Use Key Data

The only data we maintain is used exclusively for:

  • Script Authentication - Verifying valid license keys when scripts are executed
  • Access Control - Ensuring only authorized users can run our scripts
  • Security - Preventing key sharing and unauthorized distribution

3. Data Storage and Security

All remaining data is handled through Polsec's secure infrastructure:

  • Encryption: All key data is encrypted at rest and in transit
  • Third-Party Storage: Key data is managed entirely by Polsec's systems
  • No Local Storage: We maintain no local databases or file storage of user data
  • Minimal Retention: Only active key data is retained; expired keys are periodically purged

4. Data Sharing and Disclosure

We do not sell, trade, or rent any information to third parties. The limited key data we have is:

  • Never Sold: We do not monetize user data in any way
  • Stored Exclusively: Key data remains within Polsec's ecosystem
  • Legal Compliance: Only disclosed if required by valid legal process

🔒 We have never and will never sell any user information.

5. Your Rights and Choices

Even with minimal data collection, you maintain full rights:

  • Access: Request information about any key data associated with you
  • Deletion: Request removal of your key and associated data
  • Opt-out: Simply stop using our scripts to discontinue any data association

📧 To exercise your rights: Contact us via Discord or email rawr.xyl@gmail.com. Since we store minimal data, most requests can be fulfilled quickly.
