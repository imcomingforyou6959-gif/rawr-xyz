Privacy Policy

Last updated: November 15, 2026

1. What we collect

We keep this short on purpose. Here is exactly what reaches our servers.

1.1 Data we keep on violators

  • Violation records: Only users who break our Terms of Service have information retained about them.
  • HWID: The hardware identifier your executor generates. Stored to keep banned users from returning.
  • Account details: Username, display name, and user ID of violators.

1.2 Short-lived data we keep on everyone

To keep the API from being flooded, we track a small amount of data on every session, not just violators. This data expires automatically and is never used to identify you.

  • Rate-limit counters: A count of requests per HWID and per IP, so we can throttle abuse. Expires within minutes.
  • Network group tracking: HWIDs seen from the same network range. Used to catch bot farms that rotate addresses inside one block. Expires within 24 hours.
  • Session records: A short-lived record tied to your active session so we can verify that each request comes from the client we handed the session to. Expires within minutes.

None of the data in 1.2 is linked to your username, and none of it survives past its expiry window.

1.3 What we never collect

  • Browsing history, cookies for advertising, or tracking pixels.
  • Your Roblox password, email, or payment information.
  • Any data from your device beyond what your executor and Roblox already expose to a script.

2. Execution logs

When you run one of our scripts, a small status panel shows your username, display name, HWID, the current time, and the game you're in. This is a local display. It is not saved to disk, not uploaded as a log file, and not kept after the session ends.

Separately, while a session is active, our loader sends a periodic check-in to our API with your HWID, username, display name, user ID, executor name, and the game's identifiers. This check-in exists so that a ban applied mid-session takes effect without waiting for the next launch. It is stored alongside your session record and expires with it.

No chat messages, game content, or screen data is ever captured or transmitted. The check-in contains only the fields listed above.

3. Client checks

Every request to our API includes identifying headers sent by your client. We read them for one reason: to tell a normal executor apart from a bot or an impersonator.

3.1 What triggers action

  • Blacklisted clients: Known automated tools are blocked on sight. A violation record is created and the request is denied.
  • Impersonation: If a client claims to be one executor while its headers identify a different one, the request is flagged and reported.

3.2 What does not trigger action

  • Standard Roblox clients, browsers, and mobile devices are ignored. Nothing is stored.
  • Unknown or unverifiable clients are allowed through without being reported or flagged.
  • We do not build profiles from client headers and do not use them for advertising or analytics.

4. IP addresses and network data

Every request includes your IP address. We use it for security only, and it is handled differently depending on the check.

  • Rate limiting: The full IP is stored as a counter key alongside your HWID to throttle requests. Expires within minutes to 24 hours depending on the limit.
  • Network abuse detection: We store the network range of your IP and the HWIDs seen from it. Expires within 24 hours.
  • Location consistency: We store the country associated with your IP, not the IP itself, to detect a single HWID appearing in distant locations faster than physically possible.
  • Connection classification: We look up basic information about the network your IP belongs to so we can tell residential, datacenter, and proxy connections apart and apply sensible rate limits to each. The result is cached for up to 24 hours. See Section 10 for the third-party service involved.

IP data is used only for the checks above. It is never used for advertising, analytics, profiling, or tracking, and it is not sold or shared except as described in Section 10.

5. Sessions

When a session starts, our API and your loader establish a secure channel that is used to sign and encrypt the scripts you download.

  • Server side: We store a short-lived session record so we can verify that each request comes from the client we handed the session to. It expires automatically within minutes.
  • Client side: Your private key never leaves your device. The loader may write a small session cache to your executor's workspace so the next launch can start faster. You can delete this file at any time.

6. How we use what we store

  • Enforcement: Identifying and blocking users who break the Terms of Service.
  • Ban management: Keeping banned HWIDs and account details on file so banned users cannot return on the same hardware.
  • Rate limiting: Keeping the API available by throttling floods, bot farms, and scrapers.

If you follow the Terms of Service, nothing about you is kept past the short expiry windows described in Section 1.2.

7. Storage and security

  • Encryption: Stored data is encrypted at rest and in transit.
  • Access: Only staff who handle enforcement can read violation records.
  • Retention: Violation records are kept while the ban is active. Rate-limit and network keys expire on their own within 24 hours.
  • Audits: Stored records are reviewed periodically for accuracy.

8. Sharing

We do not sell, trade, or rent user data. It is used inside rawr.xyz for enforcement, with one exception: your IP address is sent to a third-party network information service described in Section 10.

We will disclose stored data only if compelled by valid legal process.

9. Your rights

  • Access: You can ask what we have stored about you.
  • Deletion: You can ask for anything not tied to an active violation to be removed.
  • Avoidance: Following the Terms of Service means nothing beyond short-lived rate-limit keys is stored in the first place.

To make a request, contact us on Discord or at rawr.xyl@gmail.com. Because violator records are the only long-lived data we hold, most requests are resolved the same day.

10. Third-party services

We use a small number of services to run the site and API. Each has its own privacy policy.

  • Vercel: Hosts the API and processes incoming requests.
  • Upstash Redis: Stores session records, rate-limit counters, network trackers, and violation records.
  • GitHub: Hosts script files and version history.
  • Discord: Hosts the community server.
  • ip-api.com: Receives your IP address when we need basic network information about it. Only the IP is sent. No HWID, username, display name, user ID, or session data is included in the lookup. The result is cached in our own storage so repeat lookups from the same IP do not hit the service again.

11. Children

Our services are not directed at children under 13, and we do not knowingly collect information from them.

12. Changes

If this policy changes, the new version will appear here with an updated date. Significant changes will be announced on Discord. Continuing to use the service after a change means you accept the updated policy.

13. Contact

  • Discord: Our community server
  • Email: rawr.xyl@gmail.com
  • Typical response: 24–48 hours

14. Consent

Using the site or the scripts means you accept this policy. If you do not, please stop using the service.
